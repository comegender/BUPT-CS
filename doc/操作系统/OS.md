# OS

## chapter1

* 操作系统是计算机系统资源的管理者
  * CPU管理，内存管理，文件管理，设备管理
* 操作系统是用户和计算机硬件系统之间的接口
  * 命令接口（交互式/联机命令、批处理/脱机命令）
* 操作系统的特征
  * 并发、共享、虚拟、异步
  * 并发和共享是OS的两个最基本的特征、互为存在条件
* 操作系统的发展历程
  * 手工阶段->单道批处理阶段->多道批处理阶段->分时操作系统->现代操作系统
  * 单道批处理系统：内存存放单个进程，简单顺序队列
  * 多道批处理系统：内存存放多个进程，遇到I/O进程切换
  * 分时OS：内存存放多个进程，引入时间片
* 处理器运行模式：
  * 用户态（不可执行特权指令）
  * 内核态（可以执行特权指令）
* 中断（从用户态转到内核态的唯一途径）
  * 外中断（当前指令无关）：I/O完成信号、时钟中断等
  * 内中断（当前指令相关）：系统调用、除数为0、运算溢出、非法指令等

## chapter2

* 系统调用
  * 操作系统提供给应用程序的接口（公共子程序），保证稳定性和安全性
  * 功能：设备管理，文件管理，进程控制，进程通信，内存管理
  * 处理过程：传参-内核态-保存CPU现场-子程序-恢复CPU现场-用户态
* 操作系统结构
  * 分层法：高层-底层单向依赖；易调试，但是低效且不灵活
  * 模块化：按照功能分块，用接口通信；可维护性强，但接口设计复杂、调试困难
  * 微内核：相对于宏内核性能降低，但有高可拓展性，可移植性，可靠性和安全性
* 操作系统的引导
  * CPU激活并跳转到BIOS（存放在ROM）-硬件自检（POST）-按启动顺序（Boot Sequence）找到并加载主引导记录（MBR）-加载分区引导记录（PBR）-加载启动管理器（Boot Manager）-加载操作系统到RAM

## chapter3&4

* 进程
  * 进程状态（PS）：就绪，运行，阻塞（等待），（创建，终止）
  * 进程状态的切换：
    * ![1762785110252](C:\Users\jzy13\AppData\Roaming\Typora\typora-user-images\1762785110252.png)
    * 就绪/阻塞区别：获得CPU后是否能立即运行，就绪态可以立即运行，阻塞态不能
  * 进程的组成：进程控制块PCB（位于内核），代码段，数据段
  * PCB：进程描述信息，进程控制信息，CPU上下文，分配的资源等
  * 进程的创建：申请空白PCB-分配资源-初始化PCB-创建态
  * 进程上下文切换
    * 将待挂起进程CPU上下文保存到PCB，并将该PCB移入就绪/阻塞队列
    * 将选择另一个进程执行，用其PCB更新CPU上下文
    * CPU跳转到新进程PC的位置开始执行
  * 进程通信：共享内存，消息传递，管道通信，信号
* 线程
  * 轻量级进程，不拥有系统资源，有线程控制块TCB
  * 一个进程中的多个线程之间也能并发执行
  * 同一进程中的不同线程分配到多个CPU上执行
  * 线程的实现：
    * 用户级线程ULT
    * 内核级线程KLT
    * ULT-KLT组合使用：多对一、一对一、多对多

## chapter5&6

* 进程调度
  * 按照某种规则，从就绪态队列进程中选择一个进程获得CPU
  * CPU调度的层次：
    * 长期调度（作业调度，高级调度）、中期调度（内存调度，中级调度）、短期调度（进程调度，低级调度）
    * 多道程序度由长期调度决定
  * 进程调度的实现：调度器（执行调度算法选出目标进程）、分配器（转移CPU控制权）
  * 进程调度的时机：
    * 进程新建，进程终止，进程阻塞，进程就绪
  * 进程调度的方式：抢占式调度、非抢占式调度
  * 调度算法的评估：CPU利用率，吞吐量，周转时间，等待时间，响应时间
  * **调度算法**
    * FCFS，SJF，SRTF，HRRF，Priority
    * RR
    * MLQ，MLFQ
* 进程同步
  * 临界资源（微观上同一时间仅允许一个进程使用的资源）
    * 竞态条件：程序的最终结果取决于多个异步并发时间的不可确定的执行顺序
    * 临界资源的访问分为4个部分：进入区，临界区，退出区，剩余区
    * 临界区问题要求：互斥，进展性，有限等待
  * 同步（多个并发进程为按照指定顺序运行而等待、传递信息所产生的制约关系）：
    * 软件实现：peterson算法
    * 硬件实现：中断屏蔽、TestAndSet、CompareAndSwap
  * 信号量（软硬件支持的同步实现，解决忙等待问题）：
    * 两个原语（由硬件支持的，不被中断执行的操作序列）：wait，signal
    * 信号量分类：二值信号量、计数型信号量
  * 管程（一次仅允许一个线程在内执行的模块，是信号量的进一步封装）：
    * 条件变量

## chapter 7&8

+ 死锁
  + 死锁产生的必要条件：互斥，持有且等待，非抢占，循环等待
  + 死锁处理的策略
    + 死锁预防：破坏上述四个条件中的一个
    + 死锁避免：银行家算法，资源分配图
    + 死锁检测和恢复
+ 内存管理
  + 地址：符号地址，逻辑地址，物理地址
  + 地址重定位：地址绑定，重定位，翻译，映射
  + 内存管理单元MMU：logical address -> physical address，内存保护，TLB（快表）
  + 物理地址 = 逻辑地址偏移量 + 段基址
    + 固定分区（MFT）：固定分区表，内部碎片
    + 动态分区（MVT）：分区表（首次适应，最佳适应，最差适应），外部碎片
    + 分段（segmentation）：分段表，极小的外部碎片
  + 物理地址 = 页基质+逻辑地址中的页内偏移量
    + 分页（page）：（多级）页表，极小的内部碎片
  + MFT/MVT：一个进程使用一个区；分段/分页：提个进程使用多个段/页

## chapter 10

逻辑文件系统

+ 文件
  + 文件属性：<名字，标识，类型，地址，权限......>
  + FCB：一个包含大部分文件属性的数据结构
  + 文件操作：创建，读，写，删除，截断
  + 文件锁：共享锁，互斥锁
  + 文件访问方法：顺序，索引，直接/随机
+ 文件目录
  + 目录是一张表，一行是一个目录项，一列是一个文件属性
  + In DOS, Directory entry=<name,identifier,type,location,protection...>
  + In Linux, Directory entry=<name,inode>, Inode=< Identifier, Type, Location, …>
  + 一级目录，二级目录，树形结构，无环图
