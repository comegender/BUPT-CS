## 1 实验任务背景 

本实验旨在通过实现动态规划算法来解决经典的0-1背包问题。0-1背包问题是组合优化中的一个NP完全问题，在资源分配、投资决策等领域具有重要的应用价值。实验要求实现基本动态规划算法和改进的优化算法，并验证其正确性和效率。

**实验目标包括：**

1. 实现基本动态规划算法解决0-1背包问题 
2. 实现改进的优化算法，提高空间效率 
3. 处理数据范围达n≤2500的输入 
4. 通过测试验证算法性能，分析不同算法的优缺点 

## 2 算法原理与设计 

### 2.1 基本动态规划算法 

0-1背包问题的基本动态规划解法基于以下递推关系：

设`dp[j]`表示容量为j的背包能获得的最大价值，则有状态转移方程：

```cpp
dp[j] = max(dp[j], dp[j - cost[i]] + value[i])
```

**算法步骤：**

1. 初始化dp数组为0 
2. 对于每个物品i，从背包容量v递减到cost[i] 
3. 更新dp[j]的值 
4. 使用标志数组flag记录选择情况，用于回溯最优解 

### 2.2 改进的优化算法 

改进算法采用分治策略，维护两个向量p和q，其中：

- `p[i]`存储前i个物品的所有非支配解（费用，价值）对 
- `q[i-1]`表示选择第i个物品后的解集 

由C［i］［j］的递归式(4-11)容易证明：在一般情况下，对每一个确定的i(1≤i≤n)，函数C［i］［j］是关于变量j的阶梯状单调不减函数(事实上，计算C［i］［j］的递归式在变量j是连续变量，即为实数时仍成立)。跳跃点是这一类函数的描述特征。在一般情况下，函数C［i］［j］由其全部跳跃点唯一确定，如图所示。

![img](https://i-blog.csdnimg.cn/blog_migrate/5b476b14fbf9a08b64cda15c3559d02b.png)

利用该类函数由其跳跃点唯一确定的性质，来对0-1背包问题的算法knapsack进行改进，具体思路如下： 

+ 对每一个确定的i(1≤i≤n)，用一个表p［i］来存储函数C［i］［j］的全部跳跃点。对每一个确定的实数j，可以通过查找p［i］来确定函数C［i］［j］的值。p［i］中的全部跳跃点(j，C［i］［j］)按j升序排列。由于函数C［i］［j］是关于j的阶梯状单调不减函数，故p［i］中全部跳跃点的C［i］［j］值也是递增排列的。

+  p［i］可通过计算p［i-1］得到。初始时令p［0］={(0，0)}。由于函数C［i］［j］是由函数C［i-1］［j］与函数C［i-1］［j-wi］+vi做max运算得到的。因此，函数C［i］［j］的全部跳跃点包含于函数C［i-1］［j］的跳跃点集p［i-1］与函数C［i-1］［j-wi］+vi的跳跃点集q［i-1］的并集。容易得知，(s，t)∈q［i-1］当且仅当wi≤s≤W且(s-wi，t-vi)∈p［i-1］。因此，容易由p［i-1］来确定跳跃点集q［i-1］，公式为 

![img](https://i-blog.csdnimg.cn/blog_migrate/8b2d77239d581f647bfc50d938ab77ea.png)

+ 另外，设(a，b)和(c，d)是p［i-1］∪q［i-1］中的两个跳跃点，当c≥a且d<b时，(c，d)受控于(a，b)，从而(c，d)不是p［i］中的跳跃点。也就是说，根据函数c［i］［j］是关于j的阶梯状单调不减函数的特征，在跳跃点集p［i-1］∪q［i-1］中，按j由小到大排序，如果出现j增加，c［i］［j］反而下降的点(j, c［i］［j］)，则不符合函数单调性，要舍弃。p［i-1］∪q［i-1］中的其他跳跃点均为p［i］中的跳跃点。

+ 由此可得，在递归地由p［i-1］计算p［i］时，可先由p［i-1］计算出q［i-1］，然后合并p［i-1］和q［i-1］，并清除其中的受控跳跃点得到p［i］。

+ 构造最优解。

第一步，初始时，i=n，j初始化为p［n］中的最大重量，m初始化为p［n］中的最优值。

第二步，检查p［i-1］中的所有点(w，v)，如果w+wi=j并且v+vi=m，则xi=1，j=w，m=v，否则xi=0。重复第二步，直到i=0为止。

**关键公式证明：**

**定理：** `q[i-1] = p[i-1] ⊕ (w_i, v_i)`

**证明：**

设p[i-1]表示前i-1个物品的所有非支配解集合，即：

```c++
p[i-1] = {(x, y) | x为总费用，y为对应最大价值，且不存在(x', y')∈p[i-1]使得x'≤x且y'≥y}
```

当考虑第i个物品时，如果选择该物品，则新的解集为：

```cpp
q[i-1] = {(x + w_i, y + v_i) | (x, y) ∈ p[i-1] 且 x + w_i ≤ V}
```

这等价于对p[i-1]中的每个解向量加上物品i的费用和价值：

```cPP
q[i-1] = p[i-1] ⊕ (w_i, v_i)
```

其中⊕表示向量加法操作。由于p[i-1]中的解都是非支配的，经过向量加法后，q[i-1]中的解也保持了非支配性质（在合并过程中会进一步去重优化）。

**合并策略：**

将p[i-1]和q[i-1]按费用排序后合并，保留费用递增且价值递增的非支配解，确保算法效率。

## 3 算法实现细节 

### 3.1 基本动态规划实现 

```CpP
int bag01() {
    for (int i = 1; i <= n; i++) {
        for (int j = v; j >= cost[i]; j--) {
            int temp = dp[j - cost[i]] + value[i];
            dp[j] = max(dp[j], dp[j - cost[i]] + value[i]);
            if (dp[j] == temp) {
                flag[i][j] = i;
            }
        }
    }
    return dp[v];
}
```

**回溯最优解：**

```cpp
void find_seq() {
    int ind = v;
    for (int i = n; i >= 1; i--) {
        if (ind >= cost[i] && flag[i][ind]) {
            s.push(i);
            ind -= cost[i];
        }
    }
}
```

### 3.2 改进算法实现 

**核心合并逻辑：**

```cpp
// 生成选择第i个物品后的解集
for (int j = 0; j < p[i - 1].size(); j++) {
    int x = p[i - 1][j].first;
    int y = p[i - 1][j].second;
    if (x + cost[i] <= v) 
        q[i - 1].push_back({x + cost[i], y + value[i]});
}

// 合并p[i-1]和q[i-1]，保留非支配解
while (a < temp.size() && b < q[i - 1].size()) {
    // 双指针合并，确保费用递增且价值递增
    if (temp[a].first == q[i - 1][b].first) {
        p[i].push_back(max(temp[a], q[i - 1][b]));
        maxm = max(temp[a++], q[i - 1][b++]).second;
    }
    else if (temp[a].first < q[i - 1][b].first) {
        p[i].push_back(temp[a]);
        maxm = temp[a++].second;
    }
    else {
        p[i].push_back(q[i - 1][b]);
        maxm = q[i - 1][b++].second;
    }
}
```

### 4.4 结果分析

1. **正确性验证**：两种算法在所有测试用例上均得到相同的最优解，验证了算法的正确性。
2. **性能对比**：基本算法实现简单，但空间开销较大，适合小规模问题改进算法通过维护非支配解集，显著减少了空间占用在稀疏解集情况下，改进算法具有更好的时间效率
3. **边界情况处理**：两种算法都能正确处理边界情况（如单个物品、无解情况）改进算法在价值分布不均时表现更稳定
4. **适用场景**：基本算法适用于问题规模较小的情况改进算法在背包容量较大、物品价值分布较广时优势明显
