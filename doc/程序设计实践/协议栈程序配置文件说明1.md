# 协议栈程序配置文件说明1

## 配置文件格式

* 使用文件类型：json
* 文件示例：config1.json

```json
{
  "version": "1.0",
  "description": "协议栈程序配置文件设计1",
  "network": {
    "ip_address": "127.0.0.1",
    "port": 5000
  },
  "device": {
    "device_id": 2025101910241752900317    
  },
  "protocol": {
    "transport": "tcp",
    "use_crc": true
  }
}
```

**字段含义描述**：

* version：字符串类型，当前程序的版本号
* description：字符串类型，对程序与配置文件的简要介绍
* network：网络通信字段，包括两个子字段
  * ip_address：字符串类型，采用ipv4的ip地址格式
  * port：整数类型，端口号（此处示例为flask框架的5000端口）
* device：本机设备相关信息字段，包括一个子字段
  * device_id：64位长整数类型，本机设备的id，格式为YYYY-MM-DD-hh-mm-xxxxxxxxxx，4位为年份，2位为月份，2位为日期，2位当前系统时间的小时，2位当前系统时间的分钟，最后采用计数器计算的10位标识。
* protocol：协议字段，包括两个子字段
  * transport：字符串类型，传输方式，采用tcp或udp的方式
  * use_crc：布尔类型，是否使用CRC校验
