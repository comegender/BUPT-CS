## 1 实验任务背景 

本实验旨在通过实现四种经典的贪心算法来解决不同的计算问题，包括单源最短路径问题（Dijkstra算法）、最小生成树问题（Prim算法和Kruskal算法）以及Huffman编码问题。这些算法在计算机网络、数据压缩、路径规划等领域具有重要的应用价值。

**实验目标包括：**

1. 实现Dijkstra算法解决单源最短路径问题 
2. 实现Prim算法和Kruskal算法解决最小生成树问题 
3. 实现Huffman编码算法进行数据压缩 
4. 通过测试验证算法性能，分析不同算法的优缺点 

## 2 算法原理与设计 

### 2.1 Dijkstra算法（单源最短路径） 

Dijkstra算法用于解决带权有向图或无向图的单源最短路径问题，要求所有权重为非负值。

**算法原理：**

- 维护一个距离数组`dis[]`，表示从源点到各顶点的当前最短距离 
- 每次选择距离源点最近且未访问的顶点，松弛其邻接顶点 
- 使用贪心策略，每次选择局部最优解 

**算法步骤：**

1. 初始化距离数组，源点距离为0，其他为无穷大 
2. 选择未访问顶点中距离最小的顶点u 
3. 对u的所有邻接顶点v进行松弛操作：`dis[v] = min(dis[v], dis[u] + Graph[u][v])` 
4. 标记u为已访问，重复步骤2-3直到所有顶点被访问 

### 2.2 Prim算法（最小生成树） 

Prim算法用于构建无向图的最小生成树，从单个顶点开始逐步扩展。

**算法原理：**

- 维护一个集合S，包含已加入生成树的顶点 
- 每次选择连接S与V-S的最小权值边加入生成树 
- 使用贪心策略保证每次加入的边都是当前最优选择 

**算法步骤：**

1. 初始化距离数组，源点距离为0，其他为无穷大 
2. 选择未访问顶点中距离生成树最近的顶点u 
3. 将u加入生成树，更新u的邻接顶点到生成树的距离 
4. 重复步骤2-3直到所有顶点加入生成树 

### 2.3 Kruskal算法（最小生成树） 

Kruskal算法通过排序和并查集来构建最小生成树。

**算法原理：**

- 将所有边按权值从小到大排序 
- 依次选择不会形成环的边加入生成树 
- 使用并查集高效判断是否形成环 

**算法步骤：**

1. 将所有边按权值排序 
2. 初始化并查集，每个顶点独立成集合 
3. 依次选择最小权值边，如果边的两个顶点不在同一集合则加入生成树 
4. 重复步骤3直到生成树包含V-1条边 

### 2.4 Huffman编码算法 

Huffman编码用于数据压缩，根据字符出现频率构建最优前缀码。

**算法原理：**

- 频率越高的字符编码越短，频率越低的字符编码越长 
- 通过构建Huffman树实现最优编码 
- 使用优先队列（最小堆）选择频率最小的节点合并 

**算法步骤：**

1. 创建n个叶子节点，每个节点包含字符频率 
2. 构建优先队列，按频率排序 
3. 每次取出频率最小的两个节点，合并为新节点，频率为两者之和 
4. 将新节点加入队列，重复步骤3直到只剩一个节点 
5. 计算加权路径长度：`WPL = Σ(频率 × 编码长度)` 

## 3 算法实现细节 

### 3.1 Dijkstra算法实现 

采用数学归纳法证明Dijkstra算法的正确性。

**基础情况：**

- 初始时，集合S只包含源点s，dis[s] = 0，显然是最短距离

**归纳假设：**

- 假设前k次选择的顶点都已获得最短路径

**归纳步骤：**

设第k+1次选择顶点u，即u是V-S中距离s最近的顶点。要证明dis[u]就是s到u的最短距离。

1. **反证法假设**：假设存在一条更短的路径P：s→...→x→y→...→u，其中x∈S，y∈V-S，且w(P) < dis[u]
2. **路径分析**：由于s到x的路径完全在S中，根据归纳假设，dis[x]是s到x的最短距离
3. **权值非负性**：因为边权非负，所以：`w(P)=dis[x]+w(x→y)+w(y→...→u)≥dis[x]+w(x→y)`
4. **算法选择矛盾**：根据算法，我们选择的是u而不是y，说明：`dis[u]≤dis[y]≤dis[x]+w(x→y)≤w(P)`
5. **矛盾得出**：这与假设w(P) < dis[u]矛盾，因此不存在这样的更短路径P

**结论：** dis[u]确实是s到u的最短距离，Dijkstra算法的贪心选择性质得证。

```
int dijkstra() {
    for (int i = 0; i < v - 1; i++) {
        int node = -1;
        // 选择未访问顶点中距离最小的顶点
        for (int j = 1; j <= v; j++) {
            if (!vis[j] && (node == -1 || dis[j] < dis[node])) {
                node = j;
            }
        }
        
        // 松弛操作：更新邻接顶点距离
        for (int j = 1; j <= v; j++) {
            dis[j] = min(dis[j], dis[node] + Graph[node][j]);
        }
        
        vis[node] = true;
    }
    return dis[v] == inf ? -1 : dis[v];
}
```

### 3.2 Prim算法实现 

采用反证法证明Prim算法的贪心选择性质。

1. **假设**：存在连通带权图G=(V,E)，设T是G的一棵最小生成树，但不包含权值最小的跨割边(u,v)，其中u∈U，v∈V-U。
2. **构造新生成树**：由于T是生成树，在T中u到v存在唯一路径p。路径p上必有一条边(u',v')连接U和V-U（因为u∈U，v∈V-U）。设这条边为e'=(u',v')，其中u'∈U，v'∈V-U。
3. **比较权值**：根据Prim算法的选择，边(u,v)是连接U和V-U的权值最小边，因此有：`w(u,v)≤w(u′,v′)`
4. **替换构造**：从T中删除边e'，加入边(u,v)，得到新生成树T'。则：`w(T′)=w(T)−w(u′,v′)+w(u,v)≤w(T)`
5. **矛盾分析**：如果*w*(*u*,*v*)<*w*(*u*′,*v*′)，则*w*(*T*′)<*w*(*T*)，这与T是最小生成树矛盾如果*w*(*u*,*v*)=*w*(*u*′,*v*′)，则*w*(*T*′)=*w*(*T*)，T'也是最小生成树且包含边(u,v)
6. **结论**：因此，必存在一棵包含边(u,v)的最小生成树，Prim算法的贪心选择性质得证。

```
int prim() {
    int res = 0;
    // 初始化第一个顶点到其他顶点的距离
    for (int i = 2; i <= V; i++) dis[i] = min(dis[i], G[1][i]);
    
    for (int i = 2; i <= V; i++) {
        int t = -1;
        int temp = inf;
        // 选择距离生成树最近的顶点
        for (int j = 2; j <= V; j++) {
            if (!vis[j] && dis[j] < temp) {
                t = j;
                temp = dis[j];
            }
        }
        
        if (t == -1) return -1; // 图不连通
        
        res += temp;
        vis[t] = true;
        // 更新新加入顶点邻接点的距离
        for (int j = 2; j <= V; j++) dis[j] = min(dis[j], G[t][j]);
    }
    return res;
}
```

### 3.3 Kruskal算法实现 

**观察Kruskal算法：**

无向连通网的最小生成树首先是一棵生成树，即它应该是一个使网中所有顶点相连通而所需边的条数为最小的子网络，且其代价和在所有生成树中为最小。因此，可以从网的连通性角度来观察Kruskal算法。

初始时，最小生成树就是网中所有顶点的集合，它们之间没有任何一条边连接，即它们自成一个连通分量。而Kruskal算法的执行过程其实就是一个选取网中权值为最小的边的过程，即将两个小的连通分量连接为较大的连通分量，直至所有顶点都在一个连通分量中为止。每当选取网中的一条边时总会出现以下两种情况之一： 

①该边所依附的两个顶点分属于不同的连通分量。这时，该边可以作为最小生成树的一条边，因为两个不同的连通分量通过这条边的连接而相连通，成为了一个连通分量 。

②该边所依附的两个顶点属于同一个连通分量。如果选取这条边作为最小生成树的一条边，则必将构成环。因为连通分量中任意两个顶点间都有路径相通，一旦再加入一条边，该边所依附的两个顶点之间就有了两条路径，即构成了环。故属于这种情况的边即使其权值小也应该舍弃

```
int kruskal() {
    int ans = 0;
    int cnt = V; // 连通分量计数
    
    // 按边权排序
    sort(G + 1, G + 1 + E);
    
    for (int i = 1; i <= E; i++) {
        int x = find(G[i].l), y = find(G[i].r);
        // 如果不在同一连通分量，加入生成树
        if (x != y) {
            fa[x] = y;
            ans += G[i].w;
            cnt--;
        }
        if (cnt == 1) break; // 已形成生成树
    }
    return cnt != 1 ? -1 : ans; // 检查是否连通
}
```

```
double HuffmenTree() {
    int m = 2 * n - 1; // Huffman树总节点数
    
    for (int i = n + 1; i <= m; i++) {
        int n1, n2;
        select(i - 1, n1, n2); // 选择两个频率最小的节点
        
        if (n1 == -1 && n2 == -1) break;
        
        // 合并节点
        nodes[i].l = n1;
        nodes[i].r = n2;
        nodes[i].v = nodes[n1].v + nodes[n2].v;
        
        nodes[n1].used = true;
        nodes[n1].p = i;
        nodes[n2].used = true;
        nodes[n2].p = i;
    }
    
    // 计算加权路径长度
    double ans = 0;
    for (int i = 1; i <= n; i++) {
        int deep = 0;
        int cur = i;
        
        while (nodes[cur].p != 0) {
            deep++;
            cur = nodes[cur].p;
        }
        
        ans += nodes[i].v * deep;
    }
    
    return ans;
}
```

### 4.4 结果分析 

1. **正确性验证**：所有算法在测试用例上均得到预期结果，验证了算法的正确性 
2. **性能分析**： **Dijkstra算法**：实现简单，适合稠密图，但在稀疏图上效率不如堆优化版本 **Prim算法**：与Dijkstra类似，适合稠密图的最小生成树问题 **Kruskal算法**：基于排序和并查集，适合稀疏图，时间复杂度更优 **Huffman编码**：使用线性选择而非堆结构，在大数据量下效率有待优化 
3. **算法选择建议**： 最短路径问题：小规模图使用朴素Dijkstra，大规模稀疏图建议使用堆优化 最小生成树问题：稠密图用Prim算法，稀疏图用Kruskal算法 数据压缩：Huffman编码是经典最优前缀码算法，实际应用可结合堆优化 
4. **改进方向**： Dijkstra和Prim算法可引入优先队列优化至O(ElogV) Huffman编码可使用最小堆实现更高效的节点选择 增加输入验证和错误处理机制
